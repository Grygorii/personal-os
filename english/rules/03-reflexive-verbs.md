# Reflexive verbs & pronouns

**Reflexive pronouns:** myself, yourself, himself, herself, itself, ourselves,
yourselves, themselves. You use one when the subject and the object are the *same
person* — the action loops back on the doer.

- *I taught **myself** grammar.* (I did it to me.)
- *She let **herself** rest.*

## Verbs that *need* the reflexive

Some verbs require it when you do the action to yourself. Dropping it sounds wrong
to a native ear even if the meaning is clear.

<a id="immerse"></a>
- **immerse yourself in** — *I **immerse myself in** English.*
  ❌ *I immerse in English.* Passive state form: *I **am immersed in** English.*
- **pride yourself on** — *He **prides himself on** accuracy.*
- **familiarize yourself with** — *Please **familiarize yourself with** the process.*
- **help yourself to** — *Help **yourself to** coffee.*

## Don't overuse it

Many verbs are already reflexive in meaning — adding "myself" is a common learner
error: *I feel tired* (not *~~I feel myself tired~~*); *I relax* (not *~~I relax myself~~*
in normal use); *I concentrate* (not *~~I concentrate myself~~*). If in doubt, ask me.

## myself for emphasis (a different use)

You can also add a reflexive for emphasis — "me, personally":
- *I did it **myself**.* (no one helped) · *The manager **himself** replied.*

## Test yourself (cold)

Add a reflexive pronoun only where it's needed:
1. *I want to immerse ___ in the language.*
2. *She relaxed ___ after work.*  (careful)
3. *He prides ___ on being on time.*
4. *We should familiarize ___ with the new tool.*
